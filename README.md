## 수정 내역

### 2.1.4
- 홈 「무엇이 얼마나 들어갔나」에 두 칸을 따로 보여 줍니다: ① 직전 AI 답변(최대 5만 자) + ② 그 전 AI 답변(넘친 기억, 최대 5만 자) = 최대 10만 자. 큰 숫자는 두 칸 합계, 비율은 보낸 전체 중 몫입니다.

### 2.1.3
- 팝업 창(편집 · 연결 · 기록 등)을 한 모양으로 통일했습니다: 같은 머리줄, 회색 동그라미 닫기, 뒤 화면 살짝 어둡게, 같은 입력 칸 · 버튼.
- 관계도 · 달력 · 사용량 · 정리 비교 창도 같은 맥 톤으로 맞추고, 화면 모드(시스템/라이트/다크)를 따르게 했습니다.
- 미리보기 막대를 홈과 같은 규칙(큰 순서로 파란 단계 · 빗금)으로 바꿨습니다.
- 빠른 창(동그라미 짧게 누르기)도 같은 톤의 목록으로 바꿨습니다.
- 홈 「확인할 것」을 누르면 인물 → 검토 칸으로 바로 갑니다. KB로 볼 때 큰 숫자도 KB(서버 한도 100KB 기준)로 보여 줍니다.
- 기능 점검: 2.0.13과 비교해 모든 버튼 동작(225개)과 설정 칸이 그대로 있는지 확인했습니다.

### 2.1.2
- 설정 · 자료 관리 화면을 홈처럼 회색 칸 + 줄 구조로 다시 짰습니다. 설명은 쉬운 말로 바꾸고, 정리 간격은 [−][+] 줄, 정리할 영역은 맥 체크박스로 바꿨습니다.
- 기억 · 떡밥 · 자료집 · 인물 화면: 알약 모양 「주입」 버튼을 「보내기」 스위치로 바꿨습니다(동작은 같음). 이어지는 카드는 한 묶음으로 보이고, 색깔 띠와 색 배지는 회색 톤으로 줄였습니다.
- AI를 부르는 버튼도 파란색 대신 회색으로 맞췄습니다.

### 2.1.1
- 「사용법」을 오토세이버 안내처럼 바꿨습니다. 사이드바 아래 「사용법」을 누르면 오른쪽에 지금 화면의 안내가 열립니다(진행 0/N · 단계 목록 · [따라 하기] · 다른 화면 안내 · 처음 여는 화면은 자동 안내).
- [따라 하기]를 누르면 진짜 버튼을 비추는 말풍선이 한 단계씩 안내하고, 그 버튼을 직접 누르면 "잘했어요!" 하고 저절로 다음으로 넘어갑니다.
- 화면별 안내: 보내기 · 기억 · 떡밥 · 자료집 · 인물 · 자료 관리 · 설정.

### 2.1.0
- 창을 맥(빅 서) 규칙으로 새로 짰습니다. 왼쪽 사이드바(신호등 · 로고 · 방 이름 · 메뉴), 위쪽 막대(제목 + 부제 · 검색 칸 · 회색 아이콘).
- 홈을 「AI에게 보내는 기억」으로 바꿨습니다. 무엇이 · 얼마나 · 켜졌는지를 한 화면에 보여 주고, 분류마다 스위치로 끄고 켭니다. 막대는 큰 순서로 파란 단계, 기억이 아닌 부분은 빗금으로 칠합니다.
- 화면 모드(시스템 / 라이트 / 다크)를 설정 맨 위에서 고를 수 있습니다.
- 자동 정리 간격을 기억 · 인물 따로 [−][+]로 정합니다.
- 「사용법」을 새로 넣었습니다. 기능마다 한 단계씩 따라 하는 안내이고, 처음 여는 사람에게 한 번 먼저 보여 줍니다.
- 날개 버튼은 지금처럼 채팅 입력창 안에 그대로 있습니다.

### 2.0.13
- macOS 스타일 화면 (반투명 창·신호등·사이드바·애플 버튼)
- 홈: 지금 상태를 쉬운 말 세 줄(기억 주입·자동 정리·알림)로 먼저 보여 줌, 전달량 숫자와 항목 목록은 접어 둠
- 서버 재검증 버튼은 문제가 있을 때만 표시
- 긴 방에서 메시지 해시를 다시 계산하지 않게 캐시, 기억 고르기 계산 사이에 입력 처리 자리를 내줌 (입력 렉 완화)

### 2.0.12
- 입력창 타이핑 때 주입 돋보기가 메시지 목록을 다시 찾지 않게 함
- 진단용 시간 측정 추가 (콘솔 `__WishPerf()`)

### 2.0.11
- 서사 고리(약속·비밀·떡밥) 주입 한도 1,500→4,000자, 연표 2,500→5,000자
- 주입 안내문: 지난 약속·비밀·당시 발언을 장면에 맞게 떠올리고 원문 그대로 인용하도록 바꿈

### 2.0.10
- AI 관련성 재검토 묶음을 동시에 보내고 최대 3→6묶음으로 넓힘 (60초 안에 검토하는 옛 기억 후보 약 2~3배)
- 묶음 일부가 실패해도 성공한 묶음 점수는 사용

### 2.0.9
- 보조 주입: 주 주입(5만 자) 칸에 못 담은 다음 순위 기억을 그 전 AI 답변에 한 블록 더 붙임 (최대 약 5만 자 추가)
- 주 주입이 서버에서 확인된 뒤에만 쓰고, 실패해도 주 주입은 그대로 유지
- 주입 확인 탭에 보조 주입 글자 수·항목 수·예시 표시

### 2.0.8
- AI가 빈 답·미완료 답을 보내거나 답의 형식·참조 검사에서 거절된 경우도 15초 뒤 자동 재시도 (최대 2번)

### 2.0.7
- AI 답 JSON이 깨져 읽지 못하면(형식 보정 재요청까지 실패한 경우) 15초 뒤 자동으로 다시 요청 (최대 2번). 깨진 답은 저장하지 않음

### 2.0.6
- 기억 정리 요청에 연표는 최근 40장과 수동 카드만 보냄 (빠진 카드는 그대로 보존)
- 자료 카드 본문이 30,000자를 넘으면 이번 RP에 이름이 나온 카드부터 30,000자까지만 본문으로 보내고 나머지는 목차로 보냄 (빠진 카드는 그대로 보존)
- 효과: 기억 정리 요청 1회당 약 5~8만 자 감소

### 2.0.5.2
- 기억+인물 통합 요청이 30만 자 한도를 넘으면 기억을 먼저 보내고, 3초 뒤 인물 정리를 이어서 실행
- 패널 버전 표시를 실제 버전과 맞춤

### 2.0.5.1
- 통합 요청 한도 초과 시 멈추지 않고 기억만 먼저 정리
- 원본 자동 업데이트 주소 제거
