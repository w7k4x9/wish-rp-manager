## 수정 내역

### 2.0.6
- 기억 정리 요청에 연표는 최근 40장과 수동 카드만 보냄 (빠진 카드는 그대로 보존)
- 자료 카드 본문이 30,000자를 넘으면 이번 RP에 이름이 나온 카드부터 30,000자까지만 본문으로 보내고 나머지는 목차로 보냄 (빠진 카드는 그대로 보존)
- 효과: 기억 정리 요청 1회당 약 5~8만 자 감소

### 2.0.5.2
- 기억+인물 통합 요청이 30만 자 한도를 넘으면 기억을 먼저 보내고, 3초 뒤 인물 정리를 이어서 실행
- 패널 버전 표시를 실제 버전과 맞춤

### 2.0.5.1
- 통합 요청 한도 초과 시 멈추지 않고 기억만 먼저 정리
- 원본 자동 업데이트 주소 제거
